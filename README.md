# RICK Web Studios

Official website for RICK Web Studios, a website development service for small businesses.

## Website

- Main page: `index.html`
- Built with plain HTML, CSS, and JavaScript — no build tools or framework required.
- Responsive layout, mobile navigation, project showcase, service descriptions, package guidance, FAQs, and enquiry calls to action.
- Features the R&G Homes project as a portfolio item. The R&G Homes site and personal portfolio remain separate.

## Before launch

1. **Set up GitHub Pages:** In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch (usually `main`) and the `/(root)` folder, then save.
2. **Connect the business WhatsApp number:** Update the WhatsApp link in `index.html` to use the dedicated business number in international digits-only format. The current link opens WhatsApp with a prefilled message but does not route directly to a specific business number.
3. Review the copy, package scope, and indicative pricing before sharing the website with prospective clients.

Once GitHub Pages is enabled, the expected project URL is:

`https://insecuritiesb.github.io/rick-web-studios/`

GitHub Pages may take a few minutes to publish after setup or a new commit.
